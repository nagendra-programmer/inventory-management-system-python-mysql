# 📦 Inventory Management System

A **menu-driven Inventory Management System** built using **Python** and **MYSQL**.  
This application helps manage products, track stock levels, and generate inventory reports.  
The project focuses on **real-world backend problem solving** without using any frameworks, strengthening core Python and SQL concepts.

---

## ✨ Features

- ➕ **Add new products**
- 📋 **View all inventory items**
- 🔍 **Search products by name or category**
- ✏️ **Update product details**
- 🗑️ **Delete products**
- ⚠️ **Low stock alert report**
- 💰 **Total inventory value calculation**
- 📤 **Export inventory data to CSV**
- 💾 **Persistent data storage using SQLite**
- 🖥️ **User-friendly command line interface**

---

## 🛠️ Technologies Used

- **Python 3**
- **MYSQL**
- **SQL (CRUD operations)**
- **Command Line Interface (CLI)**

## 📦 How to Run the Project

1️⃣ Clone the Repository
git clone https://github.com/your-username/inventory-management-system.git

2️⃣ Navigate to the Project Folder
cd inventory-management-system

3️⃣ Run the Application
python inventory.py
📌 The database file (inventory.db) will be automatically created in the project folder.

## 🧠 How the Application Works

- Uses **MYSQL** for local database storage (no setup required)
- Performs **CRUD operations** using SQL queries
- Data remains stored even after closing the application
- Input validation prevents invalid data entries
- Modular Python functions for clean and readable code
- CSV export allows inventory data sharing via Excel or Google Sheets
